# ADR-003 — Dificuldade interna de 1 a 10

- Status: Aceito
- Data: 2026-08-24

## Contexto

Rótulos Fácil, Médio e Difícil são insuficientes para progressão e adaptação futura.

## Decisão

Toda atividade terá `difficulty` inteiro entre `1` e `10`. Cada motor documentará como essa escala altera quantidade de itens, complexidade, distratores, tempo de exposição ou número de atributos.

## Consequências

- progressão mais granular;
- preparação para adaptação futura;
- necessidade de calibrar faixas por motor;
- escala não deve ser exibida diretamente para a criança.

Adaptação automática fica fora do MVP.
